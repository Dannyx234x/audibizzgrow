# AUDI BIZZGROW ENTERPRISES

A modern demo e-commerce website created for **Audi Bizzgrow Enterprises**, a phone, gadget, and accessories store located in Jimeta, Adamawa State, Nigeria.

## About the Website

This website was designed to showcase the products and services offered by Audi Bizzgrow Enterprises in a clean, professional, and mobile-friendly format.

Customers can explore available categories and contact the business directly through WhatsApp to ask about products, prices, and availability.

## Products

The website showcases categories such as:

- Smartphones
- Smartwatches
- Wireless earbuds
- Headphones
- Bluetooth speakers
- Power banks
- Chargers
- USB cables
- Phone cases
- Screen protectors
- Memory cards
- Other phone and tech accessories

## Features

- Modern responsive design
- Mobile-friendly layout
- Featured phones section
- Gadgets and accessories sections
- Product showcase cards
- WhatsApp ordering and enquiries
- Direct phone-call button
- Business information section
- Store location information
- Responsive navigation
- Professional product imagery

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts

This demo intentionally uses a lightweight frontend structure and does not require a backend or database.
